# Notes Hub

Write one page per concept or chapter. Keep each page easy to revise in ten minutes.

## Recommended note format

1. Learning objective
2. Core concepts
3. Worked example
4. Common mistake
5. Five-line revision summary
6. Practice questions

Subject starters are available for [Chemistry](chemistry/chapter-01.md), [Physics](physics/chapter-01.md), [Biology](biology/chapter-01.md), [Hindi](hindi/chapter-01.md), [English](english/chapter-01.md), and [General Studies](gs/chapter-01.md).
